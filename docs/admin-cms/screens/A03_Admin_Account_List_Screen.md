## 2. 화면 개요

관리자 계정 목록 화면은 캐치캐쉬 CMS에 접근 가능한 관리자 계정을 조회하는 화면이다.

super_admin은 관리자 이름, 이메일, 역할, 상태, 최근 로그인, 등록일을 확인하고 관리자 계정 등록 화면으로 이동할 수 있다.

또한 특정 관리자 계정에 대해 역할 변경 또는 임시 비밀번호 재설정 액션을 수행할 수 있다.

중요:

```txt
관리자 계정 관리는 super_admin 전용이다.
operator와 viewer는 관리자 메뉴를 볼 수 없다.
operator와 viewer가 직접 URL로 접근하면 A24 접근 권한 부족 화면으로 이동한다.
관리자 초대 링크는 MVP 범위에서 제외한다.
관리자 셀프 비밀번호 찾기는 MVP 범위에서 제외한다.
비밀번호 재설정은 super_admin이 임시 비밀번호를 발급하고 대상 관리자에게 별도 전달하는 방식이다.
```

---

## 3. 화면 목적

### 3.1 관리자 목적

- CMS 관리자 계정 목록을 확인한다.
- 관리자 역할을 확인한다.
- 관리자 계정 상태를 확인한다.
- 신규 관리자 계정 등록 화면으로 이동한다.
- 특정 관리자 계정의 역할을 변경한다.
- 특정 관리자 계정의 임시 비밀번호를 재설정한다.

### 3.2 시스템 목적

- CMS 접근 권한을 가진 계정을 명확히 관리한다.
- 관리자 role 기반 메뉴·기능 접근 정책과 연결한다.
- 역할 변경, 비밀번호 재설정 같은 민감 액션에 사유 입력을 강제한다.
- 관리자 계정 변경 이력을 민감 운영 로그로 남긴다.

## 6. 접근 제한 처리

operator 또는 viewer가 직접 URL로 접근하면 A24 접근 권한 부족 화면을 표시한다.

```txt
접근 권한 부족
현재 계정으로는 관리자 계정 메뉴에 접근할 수 없습니다.
super_admin 권한이 필요한 메뉴입니다.
```

사이드바에서는 operator와 viewer에게 관리자 메뉴를 노출하지 않는다.

## 13.2 팝업 목적

대상 관리자 계정의 임시 비밀번호를 재설정한다.

MVP에서는 관리자 셀프 비밀번호 찾기를 제공하지 않으므로, super_admin이 임시 비밀번호를 생성하고 대상 관리자에게 별도로 전달한다.

실패 시:

```txt

```

---

## 13.6 임시 비밀번호 표시 정책

임시 비밀번호는 보안상 1회만 표시한다.

```txt
임시 비밀번호는 한 번만 표시됩니다.
화면을 닫으면 다시 확인할 수 없습니다.
대상 관리자에게 안전한 방식으로 전달하세요.
```

단, 현재 와이어프레임에는 임시 비밀번호 표시 결과 화면은 없다.  
MVP에서 구현하려면 `비밀번호 재설정 완료 팝업`을 추가로 정의하는 것을 권장한다.

```txt
관리자 계정 목록을 불러오는 중 오류가 발생했습니다.
```

버튼:

```txt
다시 시도
```

---

## 16.4 접근 권한 없음

operator 또는 viewer가 직접 접근하면 A24 접근 권한 부족 화면으로 이동한다.

---

## 17. 보안 정책

```txt
관리자 계정 목록 API는 super_admin만 호출할 수 있다.
서버에서 role을 반드시 재검증한다.
operator와 viewer에게 관리자 메뉴를 노출하지 않는다.
관리자 비밀번호 원문은 저장하거나 표시하지 않는다.
임시 비밀번호는 1회만 표시한다.
역할 변경과 비밀번호 재설정은 민감 운영 로그로 기록한다.
현재 로그인한 super_admin 자신의 role 하향 또는 비활성화는 제한한다.
마지막 남은 super_admin 계정은 role 변경 또는 비활성화할 수 없다.
```

## 18. 운영 로그 정책

| 액션 | 로그 유형 |
|---|---|
| 관리자 계정 목록 조회 | 필요 시 민감 운영 로그 |
| 관리자 계정 등록 | 민감 운영 로그 |
| 역할 변경 | 민감 운영 로그 |
| 비밀번호 재설정 | 민감 운영 로그 |
| 관리자 상태 변경 | 민감 운영 로그 |
| 접근 권한 없는 접근 시도 | 보안 로그 또는 민감 운영 로그 |

역할 변경과 비밀번호 재설정은 반드시 실행자, 대상 관리자, 변경 전/후 값, 사유, 시각을 기록한다.

## 20. QA 체크리스트

## 20.1 권한

- [ ] super_admin은 관리자 계정 메뉴를 볼 수 있다.
- [ ] operator는 관리자 계정 메뉴를 볼 수 없다.
- [ ] viewer는 관리자 계정 메뉴를 볼 수 없다.
- [ ] operator/viewer 직접 URL 접근 시 A24로 이동한다.
- [ ] 관리자 계정 API는 서버에서 super_admin 권한을 재검증한다.

## 20.2 목록

- [ ] 관리자 이름이 표시된다.
- [ ] 관리자 이메일이 표시된다.
- [ ] 역할이 표시된다.
- [ ] 상태가 표시된다.
- [ ] 최근 로그인이 표시된다.
- [ ] 등록일이 표시된다.
- [ ] 액션 영역이 표시된다.

## 20.3 검색·필터

- [ ] 이메일로 검색할 수 있다.
- [ ] 이름으로 검색할 수 있다.
- [ ] 역할 필터가 동작한다.
- [ ] 상태 필터가 동작한다.
- [ ] 페이지네이션이 동작한다.

## 20.4 역할 변경

- [ ] 역할 변경 팝업이 열린다.
- [ ] 변경할 역할을 선택할 수 있다.
- [ ] 변경 사유를 입력해야 한다.
- [ ] 변경 사유가 없으면 적용할 수 없다.
- [ ] 역할 변경 성공 시 목록이 갱신된다.
- [ ] 역할 변경은 민감 운영 로그로 기록된다.
- [ ] 마지막 super_admin은 role 변경할 수 없다.

## 20.5 비밀번호 재설정

- [ ] 비밀번호 재설정 팝업이 열린다.
- [ ] 재설정 사유를 입력해야 한다.
- [ ] 재설정 사유가 없으면 적용할 수 없다.
- [ ] 재설정 성공 시 임시 비밀번호가 1회 표시된다.
- [ ] 비밀번호 재설정은 민감 운영 로그로 기록된다.

## 21. 개발 메모

```txt
A03은 관리자 계정 관리의 목록 화면이다.
A04 관리자 계정 등록 화면과 A05 관리자 계정 상세/수정 화면이 이어진다.
MVP에서는 초대 링크와 셀프 비밀번호 찾기를 제공하지 않는다.
관리자 이메일은 로그인 식별자로 표시 가능하지만, 사용자 이메일은 어떤 화면에서도 표시하지 않는다.
역할 변경과 비밀번호 재설정은 반드시 서버 권한 재검증이 필요하다.
마지막 super_admin 보호 로직은 필수다.
```
