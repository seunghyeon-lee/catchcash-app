## 2. 화면 개요

보안 로그 상세 화면은 보안 로그 목록에서 선택한 보안 이벤트 1건의 상세 내용을 확인하는 화면이다.

이 화면에서는 이벤트 요약, 위치 정보, 기기 및 측정 상세, 연관 유저·보물·보상 정보를 확인한다.  
우측 패널에서는 같은 유저 또는 같은 보물과 관련된 최근 보안 로그를 함께 보여준다.

중요:

```txt
보안 로그 상세는 super_admin만 접근할 수 있다.
operator와 viewer는 접근할 수 없다.
이 화면은 조회 전용이다.
유저 정지, 보상 취소, 보물 비활성화 같은 위험 액션은 이 화면에서 직접 실행하지 않는다.
필요 시 유저 상세, 보물 상세, 보상 상세 화면으로 이동해서 별도 처리한다.
사용자 이메일, 쿠폰 번호, 바코드는 표시하지 않는다.
```

---

## 3. 화면 목적

### 3.1 관리자 목적

- 특정 보안 이벤트의 발생 원인을 확인한다.
- 위치 검증 결과와 기준 좌표·실제 좌표 차이를 확인한다.
- 기기 시각과 서버 수신 시각 차이를 확인한다.
- GPS 정확도, OS, 앱 버전, 네트워크 정보를 확인한다.
- 연관 유저, 보물, 보상 상태를 확인한다.
- 같은 유저 또는 같은 보물에서 반복되는 보안 이벤트가 있는지 확인한다.
- 후속 조치가 필요하면 관련 상세 화면으로 이동한다.

### 3.2 시스템 목적

- 보안 로그 목록에서 요약한 정보를 상세하게 제공한다.
- 부정 사용 판단에 필요한 근거 데이터를 구조화해서 보여준다.
- 보안 로그 화면과 실제 운영 액션 화면을 분리한다.
- 민감 정보 노출 없이 조사에 필요한 정보만 제공한다.

## 4. 진입 조건

### 4.1 진입 경로

| 이전 화면 | 진입 액션 |
|---|---|
| A21 보안 로그 목록 | 보안 로그 행 클릭 또는 상세 클릭 |
| A18 유저 상세 | 보안 로그 요약에서 특정 로그 클릭 |
| A08 보물상자 상세 | 보물 관련 보안 로그에서 이동 가능 |
| A16 보상 상세 | 보상 관련 보안 로그에서 이동 가능 |

### 4.2 Route

```txt
/admin/security-logs/{securityLogId}
```

Next.js App Router 기준 권장 파일 경로:

```txt
app/admin/(protected)/security-logs/[securityLogId]/page.tsx
```

### 4.3 접근 가능 조건

```txt
관리자 세션 존재
admin.status = active
admin.role = 'super_admin'
```

### 4.4 접근 제한 조건

| 조건 | 처리 |
|---|---|
| 세션 없음 | `/admin/login` 이동 |
| inactive 관리자 | 세션 무효화 후 `/admin/login` 이동 |
| operator 접근 | A24 접근 권한 부족 화면 |
| viewer 접근 | A24 접근 권한 부족 화면 |
| role 없음 | A24 접근 권한 부족 화면 |

## 6. 화면 구조

와이어프레임 기준 화면 구성은 아래 순서로 확정한다.

```txt
AdminLayout
→ 상단 헤더
→ 화면 타이틀 / 로그 ID
→ 우측 유저 상세로 이동 버튼
→ 좌측 메인 영역
   → 이벤트 요약
   → 위치 정보
   → 기기 및 측정 상세
   → 연관 엔티티
→ 우측 보조 영역
   → 같은 유저 연관 로그
   → 같은 보물 연관 로그
```

## 9. 위치 정보 영역

## 9.1 목적

보안 이벤트가 위치 검증과 관련된 경우, 요청 위치와 기준 좌표 간 차이를 확인하는 영역이다.

### 표시 정보

| 항목 | 예시 | 설명 |
|---|---|---|
| 요청 위치 위도 | `37.512340` | 사용자가 요청 시 전달한 위도 |
| 요청 위치 경도 | `127.058920` | 사용자가 요청 시 전달한 경도 |
| 기준 좌표 위도 | `37.510120` | 보물 기준 위도 |
| 기준 좌표 경도 | `127.055310` | 보물 기준 경도 |
| 실제 거리 | `312.4m` | 요청 위치와 기준 좌표 간 거리 |
| GPS 정확도 | `48.2m` | 기기에서 전달한 위치 정확도 |
| 허용 반경 | `30m` | 해당 보물의 사냥 가능 반경 |
| 초과 거리 | `+282.4m` | 실제 거리 - 허용 반경 |

---

## 9.2 위치 정보 표시 제한

목록 화면에서는 정확한 좌표를 표시하지 않는 것을 원칙으로 한다.  
상세 화면에서는 super_admin 전용이므로 조사 목적상 좌표를 표시할 수 있다.

단, CSV 또는 외부 반출에는 포함하지 않는 것을 권장한다.

---

## 9.3 위치 검증 계산 기준

```txt
실제 거리 = 요청 위치와 기준 좌표 간 거리
초과 거리 = 실제 거리 - 허용 반경
허용 여부 = 실제 거리 <= 허용 반경
```

예시:

```txt
실제 거리 312.4m
허용 반경 30m
초과 거리 +282.4m
→ 획득 차단
```

## 12. 같은 유저 연관 로그 영역

## 12.1 목적

현재 보안 로그와 같은 유저에게서 발생한 최근 보안 이벤트를 보여준다.

### 표시 기준

```txt
같은 user_id
최근 7일 또는 최근 30일
최대 4~5건 표시
```

와이어프레임에서는 `최근 7일` 기준으로 표시되어 있다.

---

## 12.2 표시 정보

| 항목 | 예시 |
|---|---|
| 로그 ID | `SEC-20240115-00381` |
| 이벤트 요약 | `허용 반경 초과` |
| 발생 시각 | `2024-01-15 14:20` |
| 심각도 | `HIGH` |

### 버튼/링크

| 요소 | 동작 |
|---|---|
| 개별 로그 카드 | 해당 A22 보안 로그 상세로 이동 |
| `유저 상세에서 전체 보기` | A18 유저 상세 또는 A21 목록 userId 필터 이동 |

권장 Route:

```txt
/admin/security-logs?userId={userId}
```

## 17. 보안 정책

```txt
보안 로그 상세 API는 super_admin만 호출할 수 있다.
서버에서 role을 반드시 재검증한다.
operator와 viewer에게는 메뉴와 route 접근을 차단한다.
사용자 이메일은 API 응답에 포함하지 않는다.
쿠폰 번호와 바코드는 API 응답에 포함하지 않는다.
OAuth token, provider secret, service role key는 절대 포함하지 않는다.
로그 원문 payload는 필요한 필드만 가공해서 내려준다.
좌표는 상세 화면에서만 표시하며 CSV 반출 대상에서 제외한다.
```

| 보안 로그 상세 조회 | 민감 운영 로그 권장 |
| 같은 유저 관련 로그 조회 | 민감 운영 로그 권장 |
| 같은 보물 관련 로그 조회 | 민감 운영 로그 권장 |
| 유저 상세 이동 | 생략 가능 |
| 보물 상세 이동 | 생략 가능 |
| 보상 상세 이동 | 생략 가능 |
