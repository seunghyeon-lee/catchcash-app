> 문서 버전: `v1.0`  
> 작성일: `2026-07-26`  
> 적용 범위: 캐치캐쉬 관리자 CMS MVP  
> 화면 ID: `A10_Admin_Product_List_Screen`  
> 화면명: 상품 목록  
> 작성 목적: 바이브코딩을 위한 관리자 CMS 상품 목록 화면 단위 구현 명세  
> 관련 화면: `A11_Admin_Product_Create_Screen`, `A12_Admin_Product_Detail_Edit_Screen`, `A13_Admin_Product_Mapping_List_Screen`, `A14_Admin_Product_Mapping_Edit_Screen`

# 1. 화면 개요

상품 목록 화면은 관리자 CMS에서 운영자가 캐치캐쉬 보물상자에 연결할 수 있는 상품을 조회하는 화면이다.

관리자는 이 화면에서 상품명, 브랜드, 외부 상품 ID, 가격, 상태, 연결된 보물 수 등을 확인하고, 필터와 검색을 통해 상품을 찾을 수 있다.

이 화면은 상품을 직접 발급하거나 쿠폰 번호·바코드를 조회하는 화면이 아니다. 실제 쿠폰 발급은 사용자 앱에서 사용자가 보관함의 보상 상세를 열거나 쿠폰 받기 액션을 수행할 때 서버 발급 함수가 처리한다.

```txt
상품 조회
→ 상품 상세 확인
→ 상품 등록
→ 상품 수정
→ 보물-상품 매칭 화면으로 이동
```

---

# 2. 화면 목적

## 2.1 관리자 관점 목적

- 등록된 상품 목록을 확인한다.
- 상품 상태별로 필터링한다.
- 브랜드별로 필터링한다.
- 상품명, 브랜드명, 외부 상품 ID로 검색한다.
- 상품별 연결된 보물 수를 확인한다.
- 상품 상세 화면으로 이동한다.
- 신규 상품 등록 화면으로 이동한다.
- 현재 필터 조건 기준으로 CSV 내보내기를 실행한다.

## 2.2 시스템 관점 목적

- 보물상자와 연결 가능한 상품 데이터의 운영 기준을 제공한다.
- 외부 상품 ID 기준으로 기프티쇼비즈 상품과 내부 상품 데이터를 연결한다.
- 상품 상태가 `active`인 상품만 매칭 가능하도록 관리한다.
- 상품 목록에서 민감 정보가 노출되지 않도록 한다.

# 3. 진입 조건

## 3.1 접근 가능 role

| role | 접근 | 비고 |
|---|---:|---|
| super_admin | 가능 | 전체 조회, 등록, 수정, CSV 가능 |
| operator | 가능 | 전체 조회, 등록, 수정, CSV 가능 |
| viewer | 가능 | 조회 전용 |

## 3.2 접근 제한

| 조건 | 처리 |
|---|---|
| 관리자 세션 없음 | `/admin/login` 이동 |
| 관리자 계정 inactive | 세션 무효화 후 `/admin/login` 이동 |
| role 없음 | `/admin/access-denied` 이동 |
| 권한 없는 직접 URL 접근 | `/admin/access-denied` 이동 |

# 6. UI 구성 요소

## 6.1 페이지 타이틀

| 항목 | 내용 |
|---|---|
| 텍스트 | `상품 목록` |
| 위치 | 콘텐츠 영역 상단 좌측 |
| 구현 | 코드 텍스트 |

## 6.2 상품 등록 버튼

| 항목 | 내용 |
|---|---|
| 텍스트 | `상품 등록` |
| 위치 | 페이지 상단 우측 |
| 이동 | `/admin/products/new` |
| 노출 role | super_admin, operator |
| viewer 처리 | 버튼 숨김 |

## 6.3 검색 입력

| 항목 | 내용 |
|---|---|
| placeholder | `상품명, 브랜드, 외부 상품 ID 검색` |
| 검색 대상 | `name`, `brand_name`, `external_product_id` |
| 입력 방식 | text input |
| 동작 | 입력 후 Enter 또는 debounce 검색 |
| 초기값 | 빈 값 |

## 6.4 상태 필터

| 항목 | 내용 |
|---|---|
| 라벨 | `상태` |
| 타입 | select |
| 기본값 | 전체 |

상태 옵션:

| 표시명 | 값 | 설명 |
|---|---|---|
| 전체 | `all` | 전체 상품 |
| active | `active` | 매칭 가능 상품 |
| inactive | `inactive` | 매칭 불가 또는 운영 중지 상품 |

## 6.5 브랜드 필터

| 항목 | 내용 |
|---|---|
| 라벨 | `브랜드` |
| 타입 | select |
| 기본값 | 전체 |
| 데이터 | 등록된 상품의 브랜드 목록 |

## 6.6 정렬 필터

| 항목 | 내용 |
|---|---|
| 라벨 | `정렬` |
| 타입 | select |
| 기본값 | 최신 등록순 |

정렬 옵션:

| 표시명 | 값 |
|---|---|
| 최신 등록순 | `created_desc` |
| 오래된 등록순 | `created_asc` |
| 가격 높은순 | `price_desc` |
| 가격 낮은순 | `price_asc` |
| 연결 보물 많은순 | `mapping_count_desc` |

## 6.7 CSV 내보내기 버튼

| 항목 | 내용 |
|---|---|
| 텍스트 | `CSV 내보내기` |
| 노출 role | super_admin, operator |
| viewer 처리 | 버튼 숨김 |
| 동작 | 현재 검색·필터 조건 기준 CSV 내보내기 확인 팝업 표시 |

CSV에는 쿠폰 번호, 바코드, 사용자 이메일, 사용자 개인정보를 포함하지 않는다.

# 7. 상품 목록 테이블

## 7.1 테이블 컬럼

| 순서 | 컬럼 | 데이터 | 설명 |
|---:|---|---|---|
| 1 | 이미지 | `image_url` | 상품 이미지 또는 fallback |
| 2 | 상품명 / 브랜드 | `name`, `brand_name` | 상품명과 브랜드명 표시 |
| 3 | 외부 상품 ID | `external_product_id` | 기프티쇼비즈 상품 식별자 |
| 4 | 가격 | `price` | 원화 가격 표시 |
| 5 | 상태 | `status` | active/inactive 배지 |
| 6 | 연결 보물 수 | `active_mapping_count` | 현재 연결된 보물 수 |
| 7 | 등록일 | `created_at` | YYYY.MM.DD |
| 8 | 액션 | 상세 | 상세 화면 이동 |

## 7.2 테이블 행 표시 예시

```txt
[Image]
스타벅스 아메리카노 Tall
스타벅스
GFT-10234
4,500원
active
3개
2025.01.15
상세
```

## 7.3 상세 링크

| 항목 | 내용 |
|---|---|
| 텍스트 | `상세` |
| 이동 | `/admin/products/{productId}` |
| 모든 role | 접근 가능 |

viewer도 상세 화면에 접근할 수 있지만, 수정 버튼과 저장 액션은 노출하지 않는다.

# 9. 상태 화면

## 9.1 로딩 상태

목록 조회 중에는 테이블 영역에 skeleton row를 표시한다.

```txt
상품 목록을 불러오는 중입니다.
```

## 9.2 검색 결과 없음

와이어프레임 기준 팝업형 카드 또는 테이블 내 빈 상태로 표시한다.

```txt
검색 결과 없음
입력한 조건과 일치하는 상품이 없습니다. 검색어 또는 필터를 변경해 다시 시도해주세요.
```

권장 구현:

- 테이블 영역 안에 빈 상태 카드 표시
- 전체 페이지를 검은 dim overlay로 덮지 않는다.
- 모달처럼 보이는 와이어프레임은 상태 예시로만 사용한다.

## 9.3 목록 조회 실패

```txt
목록 조회 실패
상품 목록을 불러오는 중 오류가 발생했습니다.
[다시 시도]
```

처리:

| 버튼 | 동작 |
|---|---|
| 다시 시도 | 동일 조건으로 목록 재조회 |

## 9.4 접근 권한 없음

```txt
접근 권한 없음
이 메뉴에 접근할 수 있는 권한이 없습니다. 관리자에게 문의하세요.
```

처리:

- 원칙적으로 권한 없는 메뉴는 사이드바에서 숨긴다.
- 직접 URL 접근 시 `/admin/access-denied` 화면으로 이동한다.
- 단순 카드 상태로 페이지 내부에 표시하지 않는다.

# 12. 데이터 연동 기준

## 12.1 조회 API

```txt
GET /api/admin/products
```

## 12.2 Query Parameters

| 파라미터 | 타입 | 설명 |
|---|---|---|
| `q` | string | 상품명, 브랜드, 외부 상품 ID 검색 |
| `status` | `all` \| `active` \| `inactive` | 상태 필터 |
| `brand` | string | 브랜드 필터 |
| `sort` | string | 정렬 기준 |
| `page` | number | 페이지 번호 |
| `pageSize` | number | 페이지 크기 |

## 12.3 응답 예시

```ts
type AdminProductListItem = {
  id: string;
  name: string;
  brandName: string;
  externalProductId: string;
  price: number;
  status: 'active' | 'inactive';
  imageUrl: string | null;
  activeMappingCount: number;
  createdAt: string;
  updatedAt: string;
};
```

## 12.4 CSV API

```txt
POST /api/admin/products/export-csv
```

요청 body:

```ts
type ExportProductCsvRequest = {
  q?: string;
  status?: 'all' | 'active' | 'inactive';
  brand?: string;
  sort?: string;
};
```

# 13. 비즈니스 규칙

## 13.1 상품 상태

| 상태 | 설명 | 매칭 가능 여부 |
|---|---|---:|
| active | 운영 중인 상품 | 가능 |
| inactive | 운영 중지 또는 비활성 상품 | 불가 |

## 13.2 연결 보물 수

`연결 보물 수`는 현재 상품에 연결된 보물상자 수를 의미한다.

권장 기준:

```txt
active 상태의 treasure_product_mappings 개수
```

단, 상세 화면에서는 전체 매칭 이력과 현재 활성 매칭을 구분해서 표시할 수 있다.

## 13.3 쿠폰 데이터 노출 금지

상품 목록에서는 다음 데이터를 절대 표시하지 않는다.

```txt
쿠폰 번호
바코드 원문
마스킹된 쿠폰 번호
사용자 이메일
사용자 개인정보
기프티쇼비즈 API secret
```

# 16. 접근성 기준

- 검색 input에는 `aria-label="상품 검색"`을 제공한다.
- select에는 명확한 label을 연결한다.
- 상품 상세 링크는 키보드로 접근 가능해야 한다.
- 상태 배지는 색상만으로 구분하지 않고 텍스트를 함께 표시한다.
- CSV 내보내기 팝업은 focus trap을 적용한다.
- 팝업 닫기 시 focus는 CSV 내보내기 버튼으로 복귀한다.

# 17. QA 체크리스트

## 17.1 기본 표시

- [ ] 상품 목록 화면이 `/admin/products`에서 정상 표시된다.
- [ ] 페이지 타이틀이 `상품 목록`으로 표시된다.
- [ ] 검색, 상태 필터, 브랜드 필터, 정렬 필터가 표시된다.
- [ ] 상품 등록 버튼이 super_admin/operator에게만 표시된다.
- [ ] CSV 내보내기 버튼이 super_admin/operator에게만 표시된다.
- [ ] viewer에게 상품 등록/CSV 버튼이 표시되지 않는다.

## 17.2 검색·필터

- [ ] 상품명으로 검색된다.
- [ ] 브랜드명으로 검색된다.
- [ ] 외부 상품 ID로 검색된다.
- [ ] 상태 필터가 동작한다.
- [ ] 브랜드 필터가 동작한다.
- [ ] 정렬 변경 시 목록 순서가 변경된다.
- [ ] 검색·필터 변경 시 페이지가 1페이지로 초기화된다.

## 17.3 테이블

- [ ] 상품 이미지가 있으면 이미지가 표시된다.
- [ ] 상품 이미지가 없으면 fallback 영역이 표시된다.
- [ ] 가격이 원화 형식으로 표시된다.
- [ ] 상태 배지가 active/inactive로 표시된다.
- [ ] 연결 보물 수가 표시된다.
- [ ] 상세 클릭 시 상품 상세 화면으로 이동한다.

## 17.4 상태 화면

- [ ] 로딩 중 skeleton row가 표시된다.
- [ ] 검색 결과가 없으면 빈 상태가 표시된다.
- [ ] 목록 조회 실패 시 다시 시도 버튼이 표시된다.
- [ ] 다시 시도 클릭 시 목록을 재조회한다.
- [ ] 권한 없는 URL 접근 시 A24 접근 제한 화면으로 이동한다.

## 17.5 CSV

- [ ] CSV 내보내기 클릭 시 확인 팝업이 표시된다.
- [ ] 취소 클릭 시 팝업이 닫힌다.
- [ ] 내보내기 클릭 시 현재 필터 조건 기준 CSV가 생성된다.
- [ ] CSV에 쿠폰 번호와 바코드가 포함되지 않는다.
- [ ] CSV에 사용자 이메일이 포함되지 않는다.

# 18. 구현 시 주의사항

```txt
상품 목록은 기프티쇼비즈 API를 직접 호출하지 않는다.
상품 목록은 내부 DB에 저장된 상품 데이터만 조회한다.
상품 상태가 inactive인 경우 신규 매칭 대상으로 선택할 수 없다.
사용자 쿠폰 발급 상태와 상품 상태를 혼동하지 않는다.
상품 가격은 운영 참고용이며, 실제 발급 가능 여부는 서버와 외부 API 상태에 따라 달라질 수 있다.
```
