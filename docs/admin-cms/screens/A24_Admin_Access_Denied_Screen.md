## 2. 화면 개요

접근 권한 부족 화면은 로그인한 관리자가 현재 접근하려는 관리자 CMS 페이지에 필요한 권한을 가지고 있지 않을 때 표시되는 안내 화면이다.

이 화면은 로그인 실패 화면이 아니다.  
관리자 인증은 완료되었지만, 관리자 역할 또는 화면별 권한이 부족한 경우에만 표시한다.

```txt
관리자 로그인 성공
→ 관리자 role 확인
→ 접근하려는 route의 권한 확인
→ 권한 없음
→ A24 접근 권한 부족 화면 표시
```

---

## 3. 화면 목적

### 3.1 핵심 목적

- 권한 없는 페이지 접근을 명확하게 차단한다.
- 현재 관리자가 왜 이 페이지에 접근할 수 없는지 안내한다.
- 허용된 안전한 이동 경로를 제공한다.
- 직접 URL 접근, role 불일치, 민감 로그 접근 차단 상황을 처리한다.
- 서버 권한 검사 결과를 UI에서 사용자에게 설명한다.

### 3.2 사용자 관점 목적

- 현재 페이지에 접근할 수 없다는 사실을 즉시 이해한다.
- 자신의 역할이 해당 기능에 접근할 수 없음을 확인한다.
- 대시보드로 돌아가거나 권한 요청이 필요하다는 다음 행동을 알 수 있다.

## 4. 진입 조건

## 4.1 기본 진입 조건

아래 조건 중 하나에 해당하면 이 화면으로 진입한다.

| 조건 | 설명 |
|---|---|
| `role_missing` | 로그인은 되었지만 관리자 프로필 또는 role이 없음 |
| `permission_denied` | 현재 role이 해당 route 또는 action 권한을 가지지 않음 |
| `sensitive_log_forbidden` | 민감 로그 또는 보안 로그 접근 권한 없음 |
| `invalid_admin_profile` | 관리자 프로필 데이터가 불완전하거나 손상됨 |
| `direct_url_forbidden` | 사이드바에 없는 route를 직접 URL로 접근함 |

---

## 4.2 진입하지 않는 조건

아래 상황에서는 A24를 사용하지 않는다.

| 상황 | 처리 화면 |
|---|---|
| 이메일/비밀번호 불일치 | `A01_Admin_Login_Screen` 내부 오류 상태 |
| 계정 비활성 | `A01_Admin_Login_Screen` 내부 비활성 안내 또는 세션 무효화 |
| 계정 잠금 | `A01_Admin_Login_Screen` 내부 잠금 안내 |
| 세션 없음 | `/admin/login` 이동 |
| 세션 만료 | `/admin/login` 이동 |
| 서버 오류 | 공통 오류 화면 또는 현재 화면 오류 상태 |

## 5. Route

권장 Route는 아래와 같다.

```txt
/admin/access-denied
```

Next.js App Router 기준 권장 파일 경로:

```txt
app/admin/(protected)/access-denied/page.tsx
```

권한 차단 사유는 query parameter로 전달할 수 있다.

```txt
/admin/access-denied?reason=permission_denied
/admin/access-denied?reason=role_missing
/admin/access-denied?reason=sensitive_log_forbidden
```

단, 보안상 민감한 내부 사유는 상세하게 노출하지 않는다.

이 화면은 로그인 이후 보호 영역에서 표시되는 화면이므로 관리자 공통 레이아웃을 사용한다.

```txt

```

### 6.1 사이드바 표시 정책

사이드바는 현재 로그인한 관리자의 role 기준으로 허용된 메뉴만 표시한다.

```txt

직접 URL 접근 또는 예외 상황에서만 접근 권한 부족 화면을 표시한다.
```

### 6.2 역할별 사이드바 메뉴

| 역할 | 표시 메뉴 |
|---|---|
| super_admin | 대시보드, 보물상자, 상품, 매칭, 보상, 유저, 문의, 보안 로그, 운영 로그, 관리자 |

## 8. UI 구성 요소

## 8.1 상단 헤더

### 구성

```txt
좌측: 캐치캐쉬 CMS
우측: 검색 입력 / 현재 권한 / 관리자 아바타
```

| 요소 | 표시 기준 |
|---|---|
| 서비스명 | `캐치캐쉬 CMS` |
| 검색창 | 관리자 공통 검색 영역. 이 화면에서는 비활성 또는 일반 상태 유지 |
| 권한 | 현재 관리자 role 표시 |
| 아바타 | 관리자 이니셜 또는 기본 원형 아이콘 |

### 구현 기준

- 공통 `AdminHeader` 컴포넌트를 재사용한다.
- 접근 제한 화면이라고 해서 헤더 구조를 변경하지 않는다.
- 검색 기능은 이 화면에서 필수 동작이 아니므로 MVP에서는 입력만 표시하거나 숨길 수 있다.

## 8.2 좌측 사이드바

### 구성

```txt
메뉴
대시보드
보물상자
상품
매칭
보상
유저
문의
운영 로그
보안 로그
관리자
```

### 표시 기준

- role 기준으로 허용된 메뉴만 노출한다.
- viewer에게는 `운영 로그`, `보안 로그`, `관리자` 메뉴를 표시하지 않는다.
- operator에게는 `보안 로그`, `관리자` 메뉴를 표시하지 않는다.
- super_admin에게는 전체 메뉴를 표시한다.

### 활성 상태

접근 제한 화면에서는 특정 메뉴를 active로 표시하지 않는다.  
필요 시 사용자가 접근을 시도한 메뉴를 흐린 active 상태로 표시할 수 있으나, MVP에서는 비활성 권장.

## 8.4 접근 차단 사유 카드

### 화면 구성

```txt
접근 차단 사유
귀하의 역할(viewer)에는 이 기능의 접근 권한이 없습니다.
권한이 필요한 경우 관리자에게 요청하세요.
```

### 표시 문구 정책

`reason` 값에 따라 문구를 다르게 표시한다.

| reason | 제목 | 설명 |
|---|---|---|
| `permission_denied` | 접근 차단 사유 | `귀하의 역할({role})에는 이 기능의 접근 권한이 없습니다.` |
| `role_missing` | 관리자 권한 없음 | `관리자 역할 정보가 확인되지 않았습니다.` |
| `sensitive_log_forbidden` | 민감 로그 접근 제한 | `이 로그는 super_admin만 조회할 수 있습니다.` |
| `direct_url_forbidden` | 직접 접근 제한 | `현재 계정으로는 요청한 경로에 접근할 수 없습니다.` |
| `invalid_admin_profile` | 관리자 정보 오류 | `관리자 프로필 정보가 올바르지 않습니다.` |

### 구현 기준

- 카드형 박스로 표시한다.
- 내부 텍스트는 코드 텍스트로 구현한다.
- 민감한 테이블명, 내부 정책명, 서버 오류 상세는 노출하지 않는다.

## 8.5 다음 행동 카드

### 화면 구성

```txt
다음 행동
```

- 관리자 간 문의 기능이 별도로 없으므로, 별도 문의 등록 버튼은 MVP에서 제공하지 않는다.

## 8.6 버튼 영역

### 기본 버튼

| 버튼 | 유형 | 동작 |
|---|---|---|
| 대시보드로 | Primary | `/admin` 또는 `/admin/dashboard` 이동 |

|---|---|
| 관리자에게 문의 | MVP에서는 제거 권장 |

|---|---|
| 관리자에게 문의 | `mailto:` 링크 또는 내부 협업툴 링크 열기 |

## 9. 권한 정책

## 9.1 역할 정의

```ts
type AdminRole = 'super_admin' | 'operator' | 'viewer';
```

## 9.2 접근 제한 사유 타입

```ts
type AccessDeniedReason =
  | 'role_missing'
  | 'permission_denied'
  | 'sensitive_log_forbidden'
  | 'direct_url_forbidden'
  | 'invalid_admin_profile';
```

## 10. 동작 플로우

## 10.1 직접 URL 접근 플로우

```txt
관리자가 /admin/security-logs 접근
→ 세션 확인
→ 관리자 role 확인
→ route 권한 확인
→ 권한 없음
→ /admin/access-denied?reason=permission_denied 이동
```

## 10.2 로그인 후 role 없음 플로우

```txt
관리자 로그인 성공
→ admin_profiles 조회
→ role 없음 또는 불일치
→ /admin/access-denied?reason=role_missing 이동
```

## 10.3 민감 로그 접근 플로우

```txt
operator 또는 viewer가 민감 운영 로그 접근
→ 서버 권한 검사 실패
→ /admin/access-denied?reason=sensitive_log_forbidden 이동
```

## 11. 서버 검증 기준

UI에서 메뉴를 숨기더라도 서버에서 반드시 권한을 재검증한다.

```txt
Client Sidebar 권한 필터링
+ Server Route Handler 권한 검증
+ Supabase RLS/RPC 권한 검증
```

### 필수 검증 항목

| 검증 항목 | 설명 |
|---|---|
| 세션 존재 여부 | Supabase Auth session 확인 |
| 관리자 프로필 존재 여부 | `admin_profiles` 또는 관리자 role 테이블 확인 |
| 관리자 상태 | active 여부 확인 |
| 관리자 role | `super_admin`, `operator`, `viewer` 중 하나인지 확인 |
| route 권한 | 요청한 route 접근 가능 여부 확인 |
| action 권한 | 생성·수정·삭제·상태 변경 가능 여부 확인 |

## 12.2 오류 상태

권한 부족이 아니라 서버 조회 실패인 경우 A24로 보내지 않는다.

| 오류 | 처리 |
|---|---|
| 네트워크 오류 | 공통 오류 화면 또는 재시도 UI |
| 관리자 프로필 조회 실패 | 공통 오류 화면 |
| 권한 정책 로드 실패 | 공통 오류 화면 |
| 세션 만료 | 로그인 화면 이동 |

## 13. 문구 정의

## 13.1 기본 문구

| 위치 | 문구 |
|---|---|
| 타이틀 | `접근 권한 부족` |
| 설명 | `현재 계정으로는 이 페이지에 접근할 수 없습니다.` |
| 카드 제목 1 | `접근 차단 사유` |
| 카드 제목 2 | `다음 행동` |
| 버튼 | `대시보드로` |

## 13.2 사유별 문구

| 상태 | 문구 |
|---|---|
| viewer 권한 부족 | `귀하의 역할(viewer)에는 이 기능의 접근 권한이 없습니다.` |
| operator 권한 부족 | `귀하의 역할(operator)에는 이 기능의 접근 권한이 없습니다.` |
| role 없음 | `관리자 역할 정보가 확인되지 않았습니다.` |
| 보안 로그 제한 | `보안 로그는 super_admin만 조회할 수 있습니다.` |
| 관리자 계정 제한 | `관리자 계정 관리는 super_admin만 접근할 수 있습니다.` |

## 14. 접근성 기준

| 항목 | 기준 |
|---|---|
| 페이지 제목 | `h1`으로 `접근 권한 부족` 사용 |
| 카드 제목 | `h2` 또는 `h3` 사용 |
| 버튼 | 실제 `button` 또는 `Link` 사용 |
| 키보드 이동 | 대시보드 버튼에 focus 가능 |
| 색상 의존 | 색상만으로 권한 부족을 표현하지 않음 |
| 스크린리더 | 접근 차단 사유를 텍스트로 읽을 수 있어야 함 |

## 19. 최종 구현 기준 요약

```txt
A24는 로그인 실패 화면이 아니다.
A24는 로그인 이후 권한이 부족한 관리자에게 표시되는 보호 영역 화면이다.
사이드바는 role 기준으로 허용 메뉴만 표시한다.
권한 없는 메뉴는 숨기고, 직접 URL 접근 시 A24를 표시한다.
관리자에게 문의 버튼은 MVP에서는 제거하고 안내 문구로 대체한다.
UI 권한 처리와 별개로 서버에서 반드시 권한을 재검증한다.
```
