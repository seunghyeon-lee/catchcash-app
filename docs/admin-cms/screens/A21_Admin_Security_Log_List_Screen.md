## 2. 화면 개요

보안 로그 목록 화면은 캐치캐쉬 사용자 앱과 관리자 CMS에서 발생한 보안성 이벤트를 super_admin이 조회하는 화면이다.

이 화면에서는 의심 이벤트, 비정상 접근, 위치 검증 실패, 반복 실패, 권한 오류, 관리자 보안 이벤트 등을 확인할 수 있다.

중요:

```txt
보안 로그는 super_admin만 조회할 수 있다.
operator와 viewer는 접근할 수 없다.
보안 로그는 조회 전용이다.
이 화면에서 유저 정지, 보상 취소, 보물 삭제 같은 위험 액션을 직접 수행하지 않는다.
필요 시 관련 상세 화면으로 이동해서 별도 권한 검증 후 처리한다.
사용자 이메일, 쿠폰 번호, 바코드는 표시하지 않는다.
```

---

## 3. 화면 목적

### 3.1 관리자 목적

- 서비스 내 보안 이벤트를 확인한다.
- 위험도 높은 이벤트를 우선 파악한다.
- 특정 유저, 닉네임, 보물 ID 기준으로 보안 로그를 검색한다.
- 이벤트 유형, 위험도, 처리 상태, 기간 기준으로 필터링한다.
- 보안 로그 상세 화면으로 이동해 이벤트 맥락을 확인한다.

### 3.2 시스템 목적

- 위치 기반 보상 서비스에서 발생할 수 있는 부정 사용 징후를 기록한다.
- 운영자가 이벤트를 확인하고 후속 조치를 판단할 수 있게 한다.
- 위험 액션은 보안 로그 화면이 아닌 연관 상세 화면에서 수행하도록 분리한다.
- 보안 로그와 일반 운영 로그를 분리한다.

```txt
/admin/security-logs
```

특정 유저 기준으로 진입할 경우:

```txt
/admin/security-logs?userId={user_id}
```

특정 보물 기준으로 진입할 경우:

```txt
/admin/security-logs?treasureId={treasure_id}
```

Next.js App Router 기준 권장 파일 경로:

```txt
app/admin/(protected)/security-logs/page.tsx
```


## 9.2 이벤트 유형 필터

| 라벨 | 값 | 설명 |
|---|---|---|
| 전체 | `all` | 전체 이벤트 |
| 위치 검증 실패 | `location_validation_failed` | 사냥 또는 보상 획득 위치 검증 실패 |
| 반복 획득 시도 | `repeated_claim_attempt` | 짧은 시간 내 반복 획득 시도 |
| 비정상 접근 | `abnormal_access` | 비정상 API 또는 권한 접근 |
| 권한 오류 | `permission_denied` | 관리자 또는 사용자 권한 오류 |
| 세션 이상 | `session_anomaly` | 비정상 세션 또는 토큰 문제 |
| 보상 발급 의심 | `reward_issue_suspicious` | 보상 발급 과정의 의심 이벤트 |
| 관리자 보안 이벤트 | `admin_security_event` | 관리자 계정 관련 보안 이벤트 |

## 9.3 위험도 필터

| 라벨 | 값 | 설명 |
|---|---|---|
| 전체 | `all` | 전체 위험도 |

| 중간 | `medium` | 확인 필요 |

## 9.4 처리 상태 필터

| 라벨 | 값 | 설명 |

## 19. QA 체크리스트

## 19.1 권한

- [ ] super_admin은 보안 로그 메뉴를 볼 수 있다.
- [ ] operator는 보안 로그 메뉴를 볼 수 없다.
- [ ] viewer는 보안 로그 메뉴를 볼 수 없다.
- [ ] operator가 직접 URL 접근 시 A24로 이동한다.
- [ ] viewer가 직접 URL 접근 시 A24로 이동한다.
- [ ] 보안 로그 API는 서버에서 super_admin 권한을 재검증한다.

## 19.2 검색·필터

- [ ] 로그 ID로 검색할 수 있다.
- [ ] 유저 ID로 검색할 수 있다.
- [ ] 닉네임으로 검색할 수 있다.
- [ ] 보물 ID로 검색할 수 있다.
- [ ] 이벤트 유형 필터가 동작한다.
- [ ] 위험도 필터가 동작한다.
- [ ] 처리 상태 필터가 동작한다.
- [ ] 기간 필터가 동작한다.
- [ ] 필터 초기화가 동작한다.
- [ ] 정렬 필터가 동작한다.

- [ ] 이벤트 유형이 표시된다.
