## 2. 화면 개요

관리자 계정 상세 화면은 CMS 관리자 계정 1건의 상세 정보를 확인하고 관리하는 화면이다.

super_admin은 관리자 계정의 기본 정보, 역할 및 권한 정보, 최근 로그인 및 활동 기록, 계정 상태 요약, 관리 액션 안내를 확인할 수 있다.

또한 다음 액션을 수행할 수 있다.

```txt
역할 변경
계정 비활성화
계정 활성화
비밀번호 재설정
```

중요:

```txt
이 화면은 super_admin 전용이다.
operator와 viewer는 접근할 수 없다.
관리자 계정 삭제는 MVP에서 제공하지 않는다.
마지막 super_admin 보호 로직은 필수다.
현재 로그인한 super_admin 자신의 role 하향 또는 비활성화는 제한한다.
역할 변경, 비활성화, 활성화, 비밀번호 재설정은 모두 민감 운영 로그로 기록한다.
```

---

## 3. 화면 목적

### 3.1 관리자 목적

- 특정 관리자 계정 정보를 확인한다.
- 관리자 role과 접근 가능한 메뉴를 확인한다.
- 최근 로그인 및 활동 기록을 확인한다.
- 관리자 계정 상태를 확인한다.
- 필요 시 역할 변경, 비활성화, 활성화, 비밀번호 재설정을 수행한다.

### 3.2 시스템 목적

- 관리자 계정 권한을 안전하게 관리한다.
- 민감 액션에 사유 입력을 강제한다.
- 권한 변경이 즉시 메뉴 접근과 기능 접근에 반영되도록 한다.
- 관리자 계정 변경 이력을 민감 운영 로그로 남긴다.

## 21. 보안 정책

```txt
관리자 계정 상세 API는 super_admin만 호출할 수 있다.
서버에서 role을 반드시 재검증한다.
역할 변경, 비활성화, 활성화, 비밀번호 재설정은 모두 서버에서 재검증한다.
자기 자신의 role 하향은 차단한다.
자기 자신의 비활성화는 차단한다.
마지막 super_admin의 role 변경과 비활성화는 차단한다.
비밀번호 원문은 저장하지 않는다.
임시 비밀번호는 1회만 표시한다.
민감 액션은 모두 민감 운영 로그로 기록한다.
```

## 24. QA 체크리스트

## 24.1 권한

- [ ] super_admin은 관리자 계정 상세에 접근할 수 있다.
- [ ] operator는 접근할 수 없다.
- [ ] viewer는 접근할 수 없다.
- [ ] operator/viewer 직접 URL 접근 시 A24로 이동한다.
- [ ] 모든 API는 서버에서 super_admin 권한을 재검증한다.

## 24.2 기본 정보

- [ ] 이름이 표시된다.
- [ ] 관리자 ID가 표시된다.
- [ ] 이메일이 표시된다.
- [ ] 계정 상태가 표시된다.
- [ ] 현재 역할이 표시된다.
- [ ] 가입일이 표시된다.
- [ ] 생성자가 표시된다.
- [ ] 최근 로그인이 표시된다.

## 24.3 역할 변경

- [ ] 역할 변경 팝업이 열린다.
- [ ] 변경할 역할을 선택할 수 있다.
- [ ] 변경 사유를 입력해야 한다.
- [ ] 현재 역할과 동일한 역할은 적용할 수 없다.
- [ ] 자기 자신의 role 하향은 차단된다.
- [ ] 마지막 super_admin role 변경은 차단된다.
- [ ] 성공 시 민감 운영 로그가 기록된다.

## 24.4 계정 비활성화

- [ ] active 계정에 비활성화 버튼이 표시된다.
- [ ] 비활성화 팝업이 열린다.
- [ ] 비활성화 사유를 입력해야 한다.
- [ ] 자기 자신의 계정 비활성화는 차단된다.
- [ ] 마지막 super_admin 비활성화는 차단된다.
- [ ] 성공 시 대상 관리자 세션이 무효화된다.
- [ ] 성공 시 민감 운영 로그가 기록된다.

## 24.5 계정 활성화

- [ ] inactive 계정에 활성화 버튼이 표시된다.
- [ ] 활성화 팝업이 열린다.
- [ ] 활성화 사유를 입력해야 한다.
- [ ] 성공 시 계정 상태가 active로 변경된다.
- [ ] 성공 시 민감 운영 로그가 기록된다.

## 24.6 비밀번호 재설정

- [ ] 비밀번호 재설정 팝업이 열린다.
- [ ] 재설정 사유를 입력해야 한다.
- [ ] 성공 시 임시 비밀번호가 1회 표시된다.
- [ ] 성공 시 대상 관리자 기존 세션이 무효화된다.
- [ ] 성공 시 민감 운영 로그가 기록된다.
