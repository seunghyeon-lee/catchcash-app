# 15_1_Support_Inquiry_List_Screen

## 1. 화면 개요

- 화면명: 문의하기 리스트 화면
- 경로: `/support`
- 목적:
  - 사용자가 등록한 문의 내역을 확인할 수 있는 화면
  - 문의 상태(`읽는 중`, `해결됨`)를 확인할 수 있는 화면
  - 하단 CTA 버튼을 통해 문의 작성 화면으로 이동하는 화면
- 진입 경로:
  - `10_My_Profile_Screen` 또는 설정/내정보 영역의 `문의하기` 버튼 클릭 시 진입
- 다음 경로:
  - 하단 `문의하기` 버튼 클릭 → `/support/new`
  - 문의 카드 클릭 → `/support/[inquiryId]` 문의 상세 화면으로 이동

---

## 2. 화면 정책

- `문의하기` 버튼을 누르면 바로 문의 작성 화면으로 이동하지 않는다.
- 먼저 사용자의 문의 내역 리스트 화면(`/support`)으로 이동한다.
- 사용자는 이 화면에서 본인이 등록한 문의 목록과 처리 상태를 확인할 수 있다.
- 하단 `문의하기` CTA 버튼을 누르면 문의 작성 화면(`/support/new`)으로 이동한다.
- 문의 상태는 MVP 기준 아래 2가지를 우선 사용한다.
  - `읽는 중`
  - `해결됨`
- 관리자 CMS에서 답변 등록이 완료되면 해당 문의 상태는 `해결됨`으로 표시된다.
- 답변 등록 시 사용자 알림함에는 `문의 답변 도착` 알림이 생성될 수 있다.
- 상단 GNB와 하단 탭바는 공통 컴포넌트를 사용한다.
- 본 MD에서는 공통 아이콘/공통 탭 에셋은 별도 정의하지 않는다.

---

## 3. 레이아웃 구조

### 3-1. 상단 영역

- 공통 상단 GNB 사용
- 구성:
  - 뒤로가기
  - 서비스명 `catch cash`
  - 알림 아이콘
  - 도움말 아이콘
  - 설정 아이콘

### 3-2. 타이틀 영역

- 메인 타이틀:
  - `뭔 일 있었냐?`
- 타이틀 아래 짧은 밑줄 장식선 사용 가능
- 텍스트는 코드 텍스트로 구현한다.

### 3-3. 문의 리스트 영역

- 문의 내역 카드 리스트가 세로로 반복 배치된다.
- 각 카드에는 아래 정보가 포함된다.
  - 문의 제목
  - 등록일
  - 상태 배지
- 문의 제목은 최대 2줄까지 노출 가능하다.
- 카드 높이는 기본형 우선 사용하고, 제목이 길 경우 확장형을 사용한다.

### 3-4. 하단 CTA 영역

- 화면 하단에 `문의하기` 버튼을 고정 또는 하단 리스트 이후 배치한다.
- 클릭 시 `/support/new`로 이동한다.

### 3-5. 하단 탭바

- 공통 하단 탭바 사용
- 현재 화면은 `내정보` 탭 활성 상태로 본다.

## 4. 에셋 정의

### 4-1. 문의 카드 기본형 프레임

- 파일명: `ui_frame_support_inquiry_card_rough_default.svg`
- 용도:
  - 문의 내역 리스트의 기본 카드 프레임
- 사용 위치:
  - `/support` 문의 리스트 카드
- 구현 기준:
  - 카드 외곽 프레임은 이미지 에셋으로 사용
  - 제목, 날짜, 상태 텍스트는 코드 텍스트로 오버레이한다
  - 일반 길이의 제목이 들어가는 카드에 사용한다

### 4-2. 문의 카드 확장형 프레임

- 파일명: `ui_frame_support_inquiry_card_rough_lg.svg`
- 용도:
  - 제목 줄 수가 많거나 카드 높이가 더 필요한 경우 사용하는 확장형 프레임
- 사용 위치:
  - `/support` 문의 리스트 카드 확장 상태
- 구현 기준:
  - 기본형보다 세로 높이가 큰 카드
  - 긴 문의 제목 또는 추가 정보가 필요한 카드에 사용한다

### 4-3. 상태 배지 - 해결됨

- 파일명: `ui_badge_support_status_resolved_black_rough_sm.svg`
- 용도:
  - 관리자 답변 완료 또는 해결 완료 상태 표시
- 표시 텍스트:
  - `해결됨`
- 구현 기준:
  - 배지 배경은 에셋 사용
  - 텍스트는 코드 텍스트로 처리한다
  - 카드 내부 좌측 하단 또는 지정 위치에 배치한다

### 4-4. 상태 배지 - 읽는 중

- 파일명: `ui_badge_support_status_reading_white_rough_sm.svg`
- 용도:
  - 관리자가 문의 내용을 확인 중인 상태 표시
- 표시 텍스트:
  - `읽는 중`
- 구현 기준:
  - 배지 배경은 에셋 사용
  - 텍스트는 코드 텍스트로 처리한다
  - 카드 내부 좌측 하단 또는 지정 위치에 배치한다

### 4-5. 문의하기 CTA 버튼 프레임

- 파일명: `ui_frame_support_write_button_black_rough_default.svg`
- 용도:
  - 문의 작성 화면 이동용 메인 CTA 버튼
- 표시 텍스트:
  - `문의하기`
- 동작:
  - 클릭 시 `/support/new` 이동
- 구현 기준:
  - 버튼 배경은 에셋 사용
  - 버튼 텍스트는 코드 텍스트로 처리한다
  - 화면 하단에 배치한다

## 6. 인터랙션 정의

### 6-1. 뒤로가기

- 상단 뒤로가기 클릭 시 이전 화면으로 이동
- 일반적으로 `내 프로필` 또는 직전 화면으로 복귀

### 6-2. 문의 카드 클릭

- 문의 카드 클릭 시 `15_2_Support_Inquiry_Detail_Screen`으로 이동한다.
- 이동 경로는 `/support/[inquiryId]`를 사용한다.
- 문의 상세 화면에서는 사용자가 작성한 문의 내용과 관리자 답변을 함께 확인한다.
- 관리자 답변이 아직 없는 경우 상세 화면에는 `읽는 중` 상태와 답변 대기 문구를 표시한다.

### 6-3. 문의하기 버튼 클릭

- 하단 `문의하기` 버튼 클릭 시 `/support/new` 이동

### 6-4. 알림 연계

- 관리자 답변 등록 시 사용자 알림함에 `문의 답변 도착` 알림이 생성될 수 있다
- 사용자는 알림 클릭 후 `/support/[inquiryId]` 문의 상세 화면으로 이동할 수 있다

## 9. 구현 기준

- 상단 GNB는 공통 컴포넌트를 사용한다.
- 하단 탭바는 공통 컴포넌트를 사용한다.
- 카드 프레임, 상태 배지, 하단 버튼 프레임만 개별 에셋으로 적용한다.
- 텍스트는 모두 코드 텍스트로 구현한다.
- 제목 길이에 따라 기본형/확장형 카드 프레임을 분기 사용할 수 있다.
- 모바일 WebView 기준으로 구현한다.
- 최대 너비는 기존 프로젝트 공통 기준(`max-width: 480px`)을 따른다.
- 실제 API/Supabase 연동 없이 Mock Data 기반으로 우선 구현한다.

---

## 10. 개발 메모

- 본 화면은 문의 작성 화면이 아니라 문의 내역 리스트 화면이다.
- `/support`는 리스트 화면
- `/support/new`는 문의 작성 화면
- 관리자 답변 확인용 별도 `답변함` 화면은 MVP 범위에서 만들지 않는다.
- 추후 상세 화면이 필요할 경우 `/support/[id]` 구조로 확장 가능하다.


## 10. 관련 화면 연결

| 화면 ID | Route | 역할 |
|---|---|---|
| `10_My_Profile_Screen` | `/profile` | 문의 영역 진입 버튼 제공 |
| `15_1_Support_Inquiry_List_Screen` | `/support` | 문의 내역 리스트 |
| `15_2_Support_Inquiry_Detail_Screen` | `/support/[inquiryId]` | 문의 상세 및 관리자 답변 확인 |
| `15_3_Support_Inquiry_Write_Screen` | `/support/new` | 신규 문의 작성 |

최종 플로우:

```txt
/profile
→ 문의하기
→ /support
→ 문의 카드 클릭
→ /support/[inquiryId]
```

```txt
/support
→ 문의하기 CTA
→ /support/new
→ 문의 등록
→ /support
```
